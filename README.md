Rust + Tokio 共享引擎，一套内核驱动 **GPUI 桌面 / Android / iOS / Web UI / CLI**。动态分段 + 慢分段救援，HTTP(S) · FTP · BitTorrent · eD2K · HLS · DASH 全覆盖；浏览器扩展三层拦截接管下载，内置 MCP 服务让 AI 也能帮你管理任务。**免费开源，没有广告，本地下载不需要账号。**
